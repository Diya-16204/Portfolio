# Shambhavi Mishra — portfolio

Static portfolio built with Vite. The copy is grounded in the supplied résumé files and the linked GitHub repositories. Project-preview images are saved locally under `public/images`; no remote screenshot host is required for them.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Content notes
